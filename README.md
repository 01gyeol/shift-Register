# 8-bit Shift Register

## 📌 동작 원리 (Operation Principle)
이 프로젝트는 4개의 D 플립플롭으로 구성된 4비트 시프트 레지스터 모듈(`shift_reg_4bit.v`) 두 개를 인스턴스화하여 직렬로 연결한 8비트 시프트 레지스터입니다. 

단일 클럭(Clock) 신호가 두 모듈에 공통으로 인가되어 전체 시스템이 완벽하게 동기화되어 작동합니다. 첫 번째 레지스터(`U1`)의 데이터 입력 핀(`sin`)으로 들어온 신호는 클럭에 맞춰 한 칸씩 이동하며, 4번째 클럭 주기에 `U1`의 마지막 출력 핀(`q1[3]`)을 빠져나와 두 번째 레지스터(`U2`)의 직렬 입력 핀(`sin`)으로 자연스럽게 넘어갑니다. 

이러한 순차적인 릴레이 방식을 통해 총 8번의 클럭 주기를 거치면, 단일 선을 이용해 8비트 길이의 데이터 직렬 전송(Serial Transmission)이 완료됩니다.

## 💡 설계 고찰 (Design Consideration)
* **모듈화와 재사용성:** 하드웨어 설계 시 코드의 재사용성(Reusability)과 모듈화(Modularization)의 중요성을 확인했습니다. 8비트 레지스터를 처음부터 새로 코딩하지 않고, 이미 검증된 4비트 레지스터 모듈을 블록 조립하듯 연결함으로써 설계 시간과 오류를 줄일 수 있었습니다.
* **직렬 전송의 장단점 이해:** 직렬 통신은 8개의 데이터 선이 필요한 병렬 통신에 비해 전송 속도는 느리지만, 핀(Pin) 수와 물리적 배선 면적을 획기적으로 줄일 수 있습니다. 
* **현대 반도체 기술과의 연계:** 이를 통해 칩렛(Chiplet) 구조나 NVLink 같은 현대 최첨단 반도체 인터페이스에서 직렬 전송(SerDes) 방식이 왜 핵심 기술로 사용되는지, 그 근간이 되는 원리를 하드웨어 코드로 직접 체감할 수 있었습니다.
